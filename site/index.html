tech6-cv-generator

Turn structured JSON into a filled-in TECH-6 CV document — without retyping the same form by hand for every expert.

TECH-6 is the CV form used in technical proposals for consulting assignments procured by multilateral development banks, including the World Bank and the Asian Development Bank. This tool is not affiliated with or endorsed by any of them.

What it is

A Python CLI and library that generates TECH-6 curriculum vitae documents (.docx) from structured JSON. Missing fields are highlighted in yellow in the document, and every batch run ends with a generation_report.json saying what succeeded, what failed, and what was highlighted. It can also map a differently-shaped schema (for example a Kosovo-style expert_profile document) into TECH-6 first, and extract text from PDF or DOCX resumes.

How it works

Install and use the CLI

git clone https://github.com/enonymous1/tech6-cv-generator.git
cd tech6-cv-generator
pip install .
tech6-cv-generator generate examples/sample_data.json
# -> outputs/Form_TECH-6_CV_Jane_Q._Expert.docx

An existing output file is never overwritten (a numeric suffix is appended), one bad input does not kill a batch run, and the process exits non-zero if anything failed. Full documentation is in the repository README.

Author the JSON in your browser

Fill in the form, check the gaps list, and download a JSON file the CLI accepts as-is. Nothing you type leaves this page — there is no server and no upload; the download is built locally in your browser. This page does not generate the DOCX itself: that step still runs with the Python CLI, as shown below the form.

Dates are printed in the DOCX exactly as entered here. If you map a schema with the CLI instead, DD/MM/YYYY dates are normalized day-first.
